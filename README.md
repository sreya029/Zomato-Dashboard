# Zomato Restaurants Analysis (Interactive Dashboard creation using MS Excel)
## Project Objective 
You are hired as a consultant data analyst by zomato where the team is looking for expansion and opening restaurants. Your task is to come up with strategies/suggestions about opening newer restaurants.
## DataSet Used
- <a href="https://github.com/sreya029/Zomato-Dashboard/blob/main/Zomato_Data_final.xlsx">Data of Zomato Restaurant </a>
## Process
- Collected and cleaned Zomato restaurant data in Excel
- Analyzed market demand, competition, and cuisine preferences
- Created dynamic Pivot Tables and interactive charts
- Designed a user-friendly Excel dashboard with filters and KPIs
- Derived insights to recommend optimal locations and cuisines for expansion

## Zomato-Dashboard
Developed an interactive Excel dashboard to analyze market demand, competition, and cuisine preferences for potential Zomato restaurant locations. Used data-driven insights to identify strategic opportunities for new restaurant openings. Enabled informed decision-making through dynamic visualizations and key performance metrics.
